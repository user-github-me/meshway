# Server discovery

A new Meshway installation has no invented public server list. Connect using an operator's invitation or explicit bootstrap address first. Server list/map entries come from a peer's actual authenticated advertisement; operator country labels are unverified metadata and permissions are checked directly on that server.

`auto_discovery: true` enables the optional server directory protocol `/meshway/server-directory/1.0.0`. The daemon queries bootstrap or manually connected peers every 15 seconds. A directory shares hints about verified public opt-in servers it knows. A receiving client queries each hinted server over authenticated libp2p transport before showing it as available and checking whether that server approves the caller. A hint cannot grant exit privileges, override same-account authentication or make a private server public.

Personal-server advertisements are never shared. Learned public addresses must be direct literal IPv4/IPv6 TCP/QUIC/WebSocket addresses; hostname addresses are excluded to prevent resolving an advertised name into the reader's LAN. Unknown private, reserved or loopback destinations are never automatically dialed. The reader can use an exact private address it already knows from a deliberate invitation. Discovery does not broadcast mDNS, enable public exits, create a worldwide directory, prove geolocation, or give a trust/reputation guarantee.

The graph is bounded: only manually supplied/bootstrap peers become directory sources; eight sources are queried per refresh; responses contain at most 16 hints and four addresses per hint; hints expire within five minutes and cannot be forwarded beyond two hops; caches and sources are limited to 128; reads have three-second deadlines; directory serving is throttled to once per remote peer per ten seconds. Learned hint expiration is retained rather than extended by forwarding. Failed or unavailable servers still require live owner verification before connecting.

Race tests verify actual owner advertisement and caller approval, refusal to auto-dial an unknown private destination, allowance of an exact manual private invitation, withholding of personal advertisements, and rejection of expired/future/excess-hop/hostname/mismatched-peer hints. No public bootstrap infrastructure is included or deployed; it requires an actual reachable operator server and release destination.
